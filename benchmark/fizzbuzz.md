# Fizz Buzz coding exercise

## Write a program in C

**Requirements:**

Write numbers from 1 to 100, after each number that is divisible by 3
(no remainder) write "fizz" and after each number that is divisible by
5 (no remainder) write "buzz", then a newline.

To test, these lines need to be part of the output

```
2
3 fizz
5 buzz
15 fizz buzz
```
